# AMARA Benchmarks

This directory contains standardized benchmark suites evaluating AMARA across key dimensions:

- **Latency & Throughput**: Retrieval speed, indexing overhead, and serialization times across varying memory store sizes.
- **Retrieval Precision & Recall**: Retrieval accuracy under diverse querying strategies and temporal decay configurations.
- **Resource Footprint**: Memory usage and serialization payload efficiency.

All benchmarks must be reproducible, automated, and decoupled from external network services.

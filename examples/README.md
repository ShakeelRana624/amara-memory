# AMARA Examples

This directory contains standalone, runnable examples demonstrating the usage of AMARA.

## Directory Structure (Planned)

- `basic/`: Minimal examples showing basic memory store, retrieve, and update operations.
- `agent_integration/`: Examples integrating AMARA with popular agent patterns and frameworks.
- `multi_agent/`: Demonstrations of shared and partitioned cognitive memory across collaborative agents.
- `custom_storage/`: Examples showing how to implement custom storage backends adhering to AMARA's storage protocols.
